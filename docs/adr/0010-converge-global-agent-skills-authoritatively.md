# Converge global agent skills authoritatively

Use the Homebrew-installed `skills` CLI to converge a profile-aware manifest of global agent skills after Homebrew on every chezmoi apply. The manifest declares profile-level target agents and ordered remote sources with selected skill names; convergence removes all existing global skills, including entries not installed by the CLI, then installs the latest upstream versions of every declared skill. Any removal, command, or post-install verification failure aborts the whole apply without rollback, so a failed run may leave no skills or a partial set until the next apply. Repository-local skill copies and links are superseded by the global set, while root agent instruction files remain repository tooling outside chezmoi's source state.
