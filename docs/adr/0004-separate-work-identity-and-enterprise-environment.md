# Separate work identity and enterprise environment

Declare `AWS_CA_BUNDLE` and `NODE_EXTRA_CA_CERTS` for the work profile, while leaving enterprise tooling as the sole owner of the files those variables reference; chezmoi must not create, overwrite, or validate those files. Store both personal and work SSH keys in 1Password and render their public keys through chezmoi's native 1Password template integration rather than committing either. Use the existing `~/DPG/` Git-directory boundary with `IdentitiesOnly` and the managed work public-key file to force the matching private identity through the 1Password SSH agent. Git applies that directory-conditional configuration during the first clone into `~/DPG/`, so no SSH host alias or special clone workflow is needed. This preserves deterministic account selection without putting key material in the public repository.
