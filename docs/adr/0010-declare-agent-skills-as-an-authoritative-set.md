# Declare agent skills as an authoritative set

Declare agent skills, including the skills used to develop this repository, as an authoritative set: a manifest in the chezmoi data directory maps each upstream source to explicit skill names or `"*"`, and a run_after script converges it on every apply by driving the Homebrew-installed `skills` CLI to install missing members, update all members to the latest upstream content, and prune undeclared managed members with a printed report of every removal. The canonical store is `~/.agents/skills`, which Codex reads natively; Claude Code consumes it through the links the CLI maintains. The CLI's global lockfile at `~/.agents/.skill-lock.json` stays unmanaged live state, and skills installed experimentally with the CLI survive until the next apply, so a skill can be trialed before it is declared. This amends ADR 0003: repository-development skills are now part of the user-level authoritative set rather than repo-local tooling, and the vendored in-repo skill copies are deleted. The rest of ADR 0003 stands; the root `AGENTS.md` and related maintenance files stay outside chezmoi's source state.
