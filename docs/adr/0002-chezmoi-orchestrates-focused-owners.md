# Let chezmoi orchestrate focused owners

Use chezmoi as the sole user-facing orchestrator, Homebrew Bundle as the owner of supported software, and small idempotent macOS scripts for system preferences, Dock layout, custom icons, and Touch ID sudo. Chezmoi installs Homebrew through a run-once-before script, then converges the rendered Brewfile afterward. A broader configuration-management system would add another orchestration layer without improving this two-profile, Apple-Silicon-macOS-only fresh-machine bootstrap. Each machine selects its `personal` or `work` profile explicitly during initialization rather than deriving intent from hostname or username. Every apply repairs managed settings drift and restores the authoritative profile-specific Dock; unresolved Dock paths may remain as macOS question-mark placeholders. Preference convergence does not restart Dock, Finder, Control Center, or other processes; values take effect on natural process restart or the documented post-bootstrap logout/login. Preserve intent comments beside opaque macOS preference keys and other non-obvious ownership or ordering constraints; omit comments that only restate a command or explain discarded Nix mechanics. A shared icon helper skips only absent targets so later applies can retry them; `fileicon` failures for existing targets remain fatal. Fonts are user-scoped. A focused idempotent script ensures the Touch ID `pam_tid.so` rule exists while preserving unrelated local PAM rules; it requests `sudo` only on drift, and the whole apply never runs as root. Use macOS's system Zsh with Homebrew's autosuggestions and syntax-highlighting formulae sourced directly; do not add a plugin manager or a second Zsh. Use Apple Git from Xcode Command Line Tools, with Homebrew owning only Git LFS. The personal profile installs Rosetta for Steam but does not install Intel Homebrew.
