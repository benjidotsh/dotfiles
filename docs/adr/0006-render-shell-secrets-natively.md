# Render shell secrets natively

Use chezmoi's native 1Password template integration to render shell secrets into a private environment file that normal shells source automatically. This keeps the design minimal and preserves current behavior, accepting plaintext in the `0600` target file and the requirement that secret-aware chezmoi reads can authenticate to 1Password. Do not add a separate `op inject` generation script. If 1Password cannot authenticate, fail without changing targets; `--skip-secrets` is an explicit escape hatch for intentionally applying only non-secret state. Fresh bootstrap first requires App Store sign-in, applies non-secret state with `--skip-secrets`, pauses for 1Password onboarding, and then performs a normal apply. With MCP servers omitted, do not retrieve or export the otherwise-unused Context7 secret.
